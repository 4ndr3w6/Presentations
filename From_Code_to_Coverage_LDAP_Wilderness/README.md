# From Code to Coverage: A Detection Engineer's Journey Through the LDAP Wilderness

**Presenter:** Andrew Schwartz

A detection-engineering walkthrough of LDAP-based Active Directory attacks and how to
build coverage for them — from LDAP Ping (`ldapnomnom` / cLDAP) username enumeration
through to correlating Event 5156 with Netlogon debug logging and honeytoken-based,
high-confidence detection.
