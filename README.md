# Presentations

Slides and demo videos from conference talks and presentations by **Andrew Schwartz**.

Each folder contains the slide deck and the demo recordings for that talk.

## Talks

### [From Code to Coverage: A Detection Engineer's Journey Through the LDAP Wilderness](./From_Code_to_Coverage_LDAP_Wilderness)
A detection-engineering walkthrough of LDAP-based Active Directory attacks and how to build coverage for them — from LDAP Ping (`ldapnomnom` / cLDAP) username enumeration to correlating Event 5156 with Netlogon debug logging and honeytoken-based, high-confidence detection.
*Slides, demo videos, and scripts in progress.*

### [You Disliked DCSync? Wait For NetSync — Texas Cyber Summit 2023](./Texas_Cyber_Summit_2023)
Charlie Clark and Andrew Schwartz on **NetSync**, a lesser-known alternative to DCSync for extracting credential material, including a new proof-of-concept and its "Golden NetSync" variant.
*Slides + 4 demo videos.*

### [SANS HackFest 2022](./SANS_HackFest_2022)
Andrew Schwartz and Charlie Clark. Demos cover Kerberos ticket forgery and analysis — Golden Ticket creation, dumping, analysis, and a Kerberos sniffer.
*Slides + 4 demo videos.*
