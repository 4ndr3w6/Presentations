# You Disliked DCSync? Wait For NetSync — Texas Cyber Summit 2023

**Presenters:** Charlie Clark and Andrew Schwartz
**Venue:** Texas Cyber Summit 2023

A look at **NetSync**, a lesser-known technique for remotely extracting credential
material from a domain controller — an alternative to the well-known DCSync — including
a new proof-of-concept and a "Golden NetSync" variant.
